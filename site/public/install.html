Install Chord

Chord is a free, open-source preview for Windows, macOS and Linux. Here’s how to install it on each, what to expect the first time you open it, and how it updates.

Windows

Windows 10 and 11, on Intel and AMD or Arm.

  • Installer for Intel and AMD
  • Installer for Arm
  1. Run the installer. It installs Chord for your account only, with no admin prompt, and opens it.
  2. If SmartScreen says Windows protected your PC, click More info, then Run anyway. The installer is signed, but SmartScreen can still warn about a new publisher’s first releases.

Updates: Chord downloads each new version in the background, only the parts that changed, and installs it when you restart. Settings → About shows when one is ready.

macOS

Apple silicon and Intel Macs.

  • Apple silicon
  • Intel
  1. Open the .dmg and drag Chord to Applications.
  2. Chord isn’t signed for macOS yet, so the first time you open it, macOS says it can’t verify it. Click Done, then:
    • macOS 15 and later: open System Settings → Privacy & Security, scroll to Security, click Open Anyway next to Chord, and confirm with your password.
    • macOS 14 and earlier: Control-click Chord in Applications, choose Open, then Open again.

Updates: Chord tells you when a new version is out. Download it and drag it over the old one; your tabs and settings stay. Afterwards macOS may ask whether Chord can use Chord Safe Storage in your keychain (it encrypts your cookies): click Always Allow. Until you answer, pages stay blank, so look for the question behind Chord’s window.

Linux

x64 and Arm, on X11 and Wayland.

Debian and Ubuntu

  • .deb for x64
  • .deb for Arm 
sudo apt install ./Chord-*.deb

The package sets up the browser’s sandbox, including on Ubuntu 23.10 and later.

Fedora and RHEL

  • .rpm for x64
  • .rpm for Arm 
sudo dnf install ./Chord-*.rpm

AppImage

  • AppImage for x64
  • AppImage for Arm 
chmod +x Chord-*.AppImage
./Chord-*.AppImage

Chord never runs without its sandbox, which needs unprivileged user namespaces. Ubuntu 23.10 and later block them for apps without an AppArmor profile, so use the .deb there.

Updates: the AppImage downloads each new version and installs it when you restart. With the .deb or .rpm, Chord tells you when a new version is out; install it the same way, over the old one. Package repositories, so apt and dnf keep Chord up to date, are coming, and so is Flathub.

Check your download

Every release lists its files’ SHA-256 checksums in SHA256SUMS.txt. Compare yours with the line for its file:

Get-FileHash .\Chord-*-setup.exe        # Windows, in PowerShell
shasum -a 256 Chord-*                    # macOS and Linux

On Windows you can also right-click the installer, choose Properties → Digital Signatures, and see it’s signed by Austin Naremore. Chord installs updates only when they’re signed the same way.

Your data

Your tabs, history, Archive, settings and Duet chats stay on your computer, in one folder:

Windows
%LOCALAPPDATA%\Chord\User Data
macOS
~/Library/Application Support/Chord
Linux
~/.config/Chord

Uninstalling keeps it, so reinstalling picks up where you left off. Delete the folder to remove it too. What Chord contacts, and why.

Uninstall

Windows
Settings → Apps → Installed apps → Chord → Uninstall.
macOS
Drag Chord from Applications to the Trash.
Linux
sudo apt remove chord, sudo dnf remove chord, or delete the AppImage.
